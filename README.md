# FoodLane Islamabad

A demo food-delivery marketplace for Islamabad, Pakistan.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build` and serve it locally with `npm run preview`.

## Demo limitations

Restaurant listings, menus, delivery fees, and orders are sample data. Orders are saved only in the current browser's local storage; no restaurant receives an order and no food is delivered.
